# WP5a — Critical Coupling Roadmap

**Status:** OPEN, held corridor

## Question

If bounded Hilbert-Schmidt coupling is too tame to produce arithmetic heat-trace structure, can arithmetic enter at the critical exponent?

The critical line for the coupling is

```text
σ = 1/2.
```

For

```text
σ > 1/2
```

`K_σ^{reg}` is Hilbert-Schmidt and Theorem F blocks the bounded heat route.

For

```text
σ ≤ 1/2
```

the kernel leaves the Hilbert-Schmidt regime and requires new regularization.

## Why this corridor is held

No claim should be made until a self-adjoint realization exists.

Required choices:

1. form-sum construction,
2. cutoff-limit construction,
3. renormalized determinant construction,
4. self-adjoint extension construction.

## First proof obligation

Define a regularized critical operator:

```text
K_{1/2}^{crit,R}
```

with cutoff `R`, then specify whether the limit

```text
R -> ∞
```

exists in any of the following senses:

```text
strong resolvent
norm resolvent
quadratic form
renormalized determinant
```

## Gate

### WP5a-live

WP5a remains live if a non-bounded or critical regularization exists and changes the trace or determinant singularity class.

### WP5a-closed

WP5a closes if every legitimate regularization restores boundedness-equivalent rigidity or fails self-adjointness.

## Claim discipline

WP5a is OPEN. It should not be advanced rhetorically until the regularization scheme is written.
