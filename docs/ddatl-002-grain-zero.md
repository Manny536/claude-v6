## Formal setup

Let `T_δ` be a finite family of `δ`-tubes in `R³`, and let `Y` be a measurable shading:

```txt
Y(T) ⊂ T,     T ∈ T_δ.
```

Define the shaded union:

```txt
U(T_δ, Y) := ⋃_{T∈T_δ} Y(T).
```

Define the pointwise multiplicity field:

```txt
m_δ(x) := #{ T ∈ T_δ : x ∈ Y(T) }.
```

Define raw excess overlap:

```txt
e_δ(x) := (m_δ(x) - 1)_+.
```

Define total shading mass and compression ratio:

```txt
ΣY := Σ_T |Y(T)|
E_δ := ∫ e_δ(x) dx
u_δ := |U(T_δ,Y)| / ΣY
```

The raw excess is not Grain Zero. It still contains overlap legally explained by Kakeya proof architecture.

## Identity I.1 — Excess mass identity

**Status:** `FORMAL`.

For any finite tube family with measurable shadings:

```txt
E_δ = ∫(m_δ - 1)_+ dx = Σ_T |Y(T)| - |U(T_δ,Y)|.
```

Reason: `m_δ = Σ_T 1_{Y(T)}` pointwise, so `∫m_δ = ΣY`; since `m_δ` is integer-valued, `min(m_δ,1)=1_U` and `(m_δ-1)_+ = m_δ - min(m_δ,1)`.

**Compression form:**

```txt
E_δ / ΣY = 1 - u_δ.
```

Consequence: raw excess generally does **not** vanish in compressed Kakeya regimes. In the compressed regime, the program cannot shrink `E_δ` itself; it must subtract legal structure.

**Status:** `FORMAL`.

Let `τ ≥ 2` and `C ∈ Adm_σ(δ,ρ)`. Define:

```txt
D_τ(C) := ∫_{{m_δ ≥ τ} \ C} e_δ dx.
```

## Pair-overlap channel

### Lemma P.1 — pair-overlap domination

**Status:** `FORMAL`.

For integer `m ≥ 0`:

```txt
(m - 1)_+ ≤ m(m - 1).
```

Therefore:

```txt
E_δ ≤ ∫ m_δ(m_δ - 1) dx = Σ_{T≠T′} |Y(T) ∩ Y(T′)|
```

with ordered pairs.

This gives a literature-contact channel: raw excess is dominated by the second factorial moment / pair-incidence mass, the type of overlap quantity manipulated in slab and product-organized incidence arguments.

### Lemma P.2 — pairwise intersections are convex-carried

**Status:** `FORMAL`.

Two `δ`-tubes around unit segments with direction angle `θ ∈ (0,π/2]` have convex intersection contained in a box of dimensions:

```txt
≲ δ × δ × min(1 + 2δ, Cδ/θ).
```

Thus level-2 pair overlap is geometrically carrier-compatible. The burden is not existence of cells; the burden is the `K2` budget.
